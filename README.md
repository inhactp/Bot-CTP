## Bot CTP 를 굴리는 스크립트입니다
### CTP 회원관리 등의 다기능 봇입니다.
#
### 아래는 기능들입니다.
- 멤버추가
    현재 멤버역할에 멤버를 추가합니다
- 멤버분기역할적용
    새로운 분기역할를 만들며 멤버역할을 가진 사람 기준으로 부여합니다. 멤버역할을 모두 부여한 후 실행하는 것이 권장됩니다
- 현재멤버재부여
    db에 따라 디스코드 멤버 역할을 재부여합니다. 운영진 역할은 부여하지 않습니다. 반대의 경우는 분기역할적용 커맨드를 사용해주세요
- 이름업데이트
    db에 현재 디스코드 닉네임들로 업데이트합니다
- 역할저장
    디스코드의 멤버/운영진 역할을 db에 동기화합니다. db에 멤버가 없다면 자동으로 자리를 생성합니다
- 랜덤뽑기
    jungol 스코어보드 기반으로 추첨 코드를 생성합니다. 생성된 코드를 /run python 으로 직접 실행해주세요
